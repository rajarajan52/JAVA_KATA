# Gilded Rose - SOLID Java Implementation

This project contains a clean Java implementation of the Gilded Rose kata following the requirements and modern SOLID design principles.

## Features

- Clear separation of item behavior via strategy classes
- Strong domain model for inventory items
- JUnit 5 tests with JaCoCo coverage enforcement
- 100% line and branch coverage validation during Maven verify
- Requirement mapping checklist to the original kata specification

## Requirement verification

See `REQUIREMENTS_CHECKLIST.md` for a direct mapping of every kata rule to the implementation.

## Run tests

```bash
mvn clean verify
```
